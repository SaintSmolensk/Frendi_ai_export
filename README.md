# Frendi Chat Exporter
Скрипт для локального экспорта диалогов Frendi AI в TXT и JSON.

## Возможности
- автоматический перехват Bearer-токена
- автоматическое определение chat ID
- выгрузка полного диалога через API Frendi
- экспорт в TXT
- экспорт в JSON
- удаление дублей сообщений
- сортировка сообщений по времени

## Использование
1. Откройте нужный диалог Frendi
2. Откройте DevTools (`F12`)
3. Вставьте содержимое `export-script.js` в консоль
4. Прокрутите чат или отправьте сообщение
5. Дождитесь завершения экспорта

## Результат
Скрипт создаёт:
- `frendi_full_export.txt`
- `frendi_full_export.json`

## Безопасность
- токены не сохраняются
- данные никуда не отправляются
- внешние серверы не используются
- вся обработка выполняется локально в браузере

## Дисклеймер
Проект не связан с Frendi AI.
Используйте скрипт ответственно и в соответствии с правилами платформы.
